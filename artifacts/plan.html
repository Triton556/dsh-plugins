1. Что делает Claude иначе

Нативные слои вместо HTML

claude.ai живёт в отдельном WebContentsView, панель и артефакты — тоже нативные view.

H = new WebContentsView({ webPreferences:{ sandbox:true,
        contextIsolation:true, nodeIntegration:false }})
contentView.addChildView(panelView)
panelView.setBounds({ x, y, width, height })

Ресайз = смена границ слоя. Shell-HTML не переобтекает вообще.

Ресайз без анимации, одна переменная

function bK(el, px){
  el?.style.setProperty("--session-panel-w", px + "px")
}
onPointerMove: bK(panelRef.current, clamp(width))
onPointerUp:   dirty && onCommit(width)   // React — только тут

Клэмпы 340 … min(720, 75%·(innerWidth−sidebar)), dirty-порог 3 px, двойной клик → 340, стрелки ±8 / Shift ±32.

2. Почему у нас дёргается

ЧтоСейчасУ ClaudeСледствие
Ширина панелиWAAPI-анимация 380 мс по grid-template-columns + width + leftпрямая запись одной CSS-переменнойтри layout-инвалидатора на кадр
Колонка чатарезиновая 1fr — переобтекает каждый кадрконтент в ограниченной центрированной колонкепере-шейпинг текста + перерисовка
Контент панели<iframe> ресайзится покадровонативный view, setBoundsмедиа перезапускается
Молния (250 искр)canvas + слой по колонке—перестала влиять: сборка 1–2 мс
200–400 мсrender на кадр при драге
4–10кадров за драг
100–600 мсgap между кадрами
1–5 мсlayout (дёшево!)

То есть дорогая не раскладка, а перерисовка. Эффект молнии после перевода на canvas перестал быть фактором — проверено A/B.

3. Стори и порядок

S0 инструменты→ S1 дивидер→ S2 чат→ S3 артефакты→ S4 регрессии→ S5 vision-QA

S0 Инструменты закрыто

  • CUA: окна, вкладки Chrome, фокус, скриншот, клик, драг, ввод
  • чтение app.asar любого Electron-пакета
  • vision проверен — скриншоты читаются
  • self-test драга из скрипта

S1 Дивидер без анимации

  • убрать WAAPI-motion
  • одна переменная --dsh-panel-w, запись на pointermove
  • grid/панель/ручка — через calc()
  • коммит на pointerup
  • клэмпы, dblclick, стрелки — как у Claude

Ожидание: медиана кадра ≤ 33 мс, p95 ≤ 50 мс.

S2 Чат не переобтекает

  • контентная колонка с max-width
  • во время драга — клип контейнера, внутренняя ширина фиксируется
  • один reflow после отпускания

Ожидание: layout ≤ 5 мс, render ≤ 16 мс.

S3 Артефакты вне рефлоу

  • contain: paint только на контейнере панели
  • iframe не меняет размер во время драга
  • проверка: mp4 не перезапускается

Ожидание: нет кадров > 50 мс, видео играет дальше.
